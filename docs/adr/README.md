# Architecture Decision Records

This directory records important architectural decisions and the reasoning behind them.

| ADR | Decision |
|---|---|
| 001 | Use Eureka for service discovery |
| 002 | Use Gateway as the external entry point |
| 003 | Use Resilience4j for fault tolerance |
| 004 | Use Tempo for distributed tracing |
| 005 | Use Loki for centralized logging |

The ADRs describe why a choice was made for this reference architecture; they are not intended to claim that the same technology is the only suitable production choice.
